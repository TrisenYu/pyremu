# 配置驱动硬件生成 + AIA/IMSIC/Hypervisor 计划

## 核心设计: TOML 配置 + Cargo build.rs 代码生成

```
config/
  qemu_virt.toml           # 单源配置 (平台预设)
  sifive_u54.toml
  custom.toml

pyremu/_native/cpu/
  build.rs                 # Cargo 构建脚本 — 读取 TOML, 生成代码
  src/config_gen.rs        # ← build.rs 自动生成 (不提交 git)
  src/
    main.rs / lib.rs       # include!(concat!(env!("OUT_DIR"), "/config_gen.rs"))

pyremu/
  platform.py              # Python 侧用 tomllib 读同一份 TOML
```

**一条配置，两侧消费**：
- **Rust**: `build.rs` → `toml` crate 解析 → 写入 `OUT_DIR/config_gen.rs` → `include!` 宏嵌入
- **Python**: `tomllib` (标准库 3.11+) 直接读取 TOML，无需代码生成

## build.rs (Cargo 构建脚本)

```rust
// pyremu/_native/cpu/build.rs
use std::{env, fs, path::Path};

fn main() {
    // 从环境变量或默认路径读配置
    let profile = env::var("PYREMU_CONFIG")
        .unwrap_or_else(|_| "qemu_virt".into());

    let config_path = Path::new("../../config").join(format!("{}.toml", profile));
    let content = fs::read_to_string(&config_path)
        .expect(&format!("Cannot read config: {}", config_path.display()));

    let cfg: toml::Value = toml::from_str(&content).unwrap();

    let out_dir = env::var("OUT_DIR").unwrap();
    let dest = Path::new(&out_dir).join("config_gen.rs");

    let mut rs = String::new();
    gen_header(&mut rs, &cfg);
    gen_isa(&mut rs, &cfg);
    gen_memory(&mut rs, &cfg);
    gen_interrupt(&mut rs, &cfg);
    gen_peripherals(&mut rs, &cfg);

    fs::write(&dest, rs).unwrap();
    println!("cargo:rerun-if-changed={}", config_path.display());
    println!("cargo:rerun-if-changed=build.rs");
}

fn gen_header(out: &mut String, cfg: &toml::Value) {
    let p = &cfg["platform"];
    writeln!(out, "// Auto-generated by build.rs from {} — do not edit.",
             cfg["platform"]["name"].as_str().unwrap_or("?"));
    writeln!(out, "pub const NUM_HARTS: u32 = {};", p["num_harts"].as_integer().unwrap());
}

fn gen_isa(out: &mut String, cfg: &toml::Value) { /* ... */ }
fn gen_memory(out: &mut String, cfg: &toml::Value) { /* ... */ }

fn gen_interrupt(out: &mut String, cfg: &toml::Value) {
    let intr = &cfg["interrupt"];
    let mode = intr["mode"].as_str().unwrap();
    writeln!(out, "#[derive(Clone, Copy, PartialEq, Eq)]");
    writeln!(out, "pub enum IntrMode {{ Legacy, Aia }}");
    writeln!(out, "pub const INTR_MODE: IntrMode = IntrMode::{};",
             match mode { "legacy" => "Legacy", "aia" => "Aia", _ => panic!() });

    match mode {
        "legacy" => {
            let c = &intr["clint"]; let p = &intr["plic"];
            writeln!(out, "pub const CLINT_BASE: u64 = {:#x};", c["base"].as_integer().unwrap());
            writeln!(out, "pub const PLIC_BASE: u64 = {:#x};", p["base"].as_integer().unwrap());
            writeln!(out, "pub const PLIC_NUM_SOURCES: u32 = {};", p["num_sources"].as_integer().unwrap());
        }
        "aia" => {
            let i = &intr["imsic"]; let a = &intr["aplic"];
            writeln!(out, "pub const IMSIC_BASE: u64 = {:#x};", i["base"].as_integer().unwrap());
            writeln!(out, "pub const IMSIC_STRIDE: u64 = {:#x};", i["per_hart_stride"].as_integer().unwrap());
            writeln!(out, "pub const APLIC_BASE: u64 = {:#x};", a["base"].as_integer().unwrap());
        }
        _ => panic!("unknown interrupt mode: {}", mode),
    }
}

fn gen_peripherals(out: &mut String, cfg: &toml::Value) {
    let devs = cfg["peripheral"].as_array().unwrap();
    // 设备枚举
    write!(out, "#[derive(Clone, Copy, PartialEq, Eq)] pub enum DeviceId {{ ");
    for d in devs { write!(out, "{}, ", d["type"].as_str().unwrap().to_uppercase()); }
    writeln!(out, "}}");

    // 设备表
    writeln!(out, "pub struct DeviceInfo {{ pub id: DeviceId, pub base: u64, pub irq: u32 }}");
    writeln!(out, "pub const DEVICES: &[DeviceInfo] = &[");
    for d in devs {
        writeln!(out, "    DeviceInfo {{ id: DeviceId::{}, base: {:#x}, irq: {} }},",
                 d["type"].as_str().unwrap().to_uppercase(),
                 d["base"].as_integer().unwrap(),
                 d["irq"].as_integer().unwrap());
    }
    writeln!(out, "];");
}
```

## Rust 引擎中的使用

```rust
// lib.rs — 嵌入生成的配置
include!(concat!(env!("OUT_DIR"), "/config_gen.rs"));

// hart_sched.rs — 编译时常量分派
fn step_interrupts(state: &mut HartState, hart_id: u8, ...) -> bool {
    match INTR_MODE {
        IntrMode::Legacy => {
            sync_mtip(state);
            sync_msip(state);
        }
        IntrMode::Aia => {
            sync_stimecmp(state);
            sync_imsic(state, hart_id);
        }
    }
    check_and_deliver_interrupt(state)
}

// 外设 MMIO 检查 — 编译时循环展开
fn is_device_addr(pa: u64) -> Option<(DeviceId, u32)> {
    for dev in DEVICES {
        if pa >= dev.base && pa < dev.base + 0x1000 {
            return Some((dev.id, dev.irq));
        }
    }
    None
}
```

## Python 侧的配置消费

Python 不生成代码 — 直接用 `tomllib` 读同一份 TOML:

```python
# pyremu/platform.py
import tomllib
from pathlib import Path

class PlatformConfig:
    @classmethod
    def from_toml(cls, profile: str = "qemu_virt") -> "PlatformConfig":
        path = Path(__file__).parent.parent / "config" / f"{profile}.toml"
        with open(path, "rb") as f:
            cfg = tomllib.load(f)
        return cls._from_dict(cfg)

    @classmethod
    def _from_dict(cls, cfg: dict) -> "PlatformConfig":
        p = cfg["platform"]; intr = cfg["interrupt"]
        return cls(
            num_harts=p["num_harts"],
            ram_base=p["ram_base"],
            ram_size=p["ram_size"],
            intr_mode=intr["mode"],
            # ... 解析外设列表
        )
```

**不再需要** Python 侧生成常量文件 — Python 代码和 Rust `build.rs` 从**同一份 TOML** 各自提取所需信息。修改配置只需编辑 TOML → 重新 `cargo build`。

## CLINT+PLIC 与 AIA 的共存 (编译时确定)

| 功能 | `legacy` 模式 | `aia` 模式 |
|------|-------------|-----------|
| IPI | CLINT MSIP (`CLINT_BASE + 4*hid`) | IMSIC `seteipnum` (`IMSIC_BASE + hid*stride`) |
| 定时器 | CLINT MTIMECMP + mtime | Sstc `stimecmp` + mtime (共享) |
| 外部中断 | PLIC claim/complete | APLIC → IMSIC MSI |
| 优先级 | PLIC priority | IMSIC `eithreshold` |
| Rust 同步函数 | `sync_msip()` / `sync_plic()` | `sync_imsic()` |
| **编译产物差异** | 链接 `clint.rs` + `plic.rs` | 链接 `imsic.rs` + `aplic.rs` |

`INTR_MODE` 是编译时常量 → `match` 表达式在优化后消除死分支 →
legacy 模式的二进制不包含 IMSIC 代码，aia 模式不包含 CLINT MSIP/PLIC 代码。**零运行时开销**。

## 实施阶段

### Phase 0: 配置基础设施 (~2 周) ★ 前置

**0a. `config/` 目录 + TOML 格式**:
- `config/qemu_virt.toml`, `config/sifive_u54.toml`
- 迁移现有 `PlatformConfig` 预设到 TOML

**0b. `build.rs` 代码生成器**:
- 依赖: `toml` crate (build-dependency only)
- 生成: `config_gen.rs` → `OUT_DIR`
- `cargo:rerun-if-changed` 指向 TOML 和 build.rs

**0c. 重构现有 Rust 代码**:
- 删除 `FfiClintCtx.base`, `FfiDevCtx.bases/ends`, `SharedMemCtx.ram_base` 等
  运行时地址参数 → 替换为 `config_gen::CLINT_BASE` 等编译时常量
- `ram_base` / `ram_size` 保留为运行时参数 (RAM 由 Python bytearray 提供,
  地址可能动态)

**0d. Python 迁移**:
- `PlatformConfig.from_toml()` → 用 `tomllib` 读配置
- 保留 `PlatformConfig` dataclass 作为运行时对象
- 删除重复的预设常量

### Phase 1: IMSIC 设备 (~1 周)

Rust 侧 `cpu/src/peripheral/imsic.rs`:
- `struct Imsic`: eip[64], eie[64], eithreshold, eidelivery
- MMIO 读写: `seteipnum`/`clreipnum` at offset 0, CSR 空间 at 0x1000+
- `sync_imsic(state, hart_id)` — 指令边界同步, 设置 `mip.SEIP/MEIP`

### Phase 2: APLIC 设备 (~1 周)

Rust 侧 `cpu/src/peripheral/aplic.rs`:
- `struct Aplic`: sourcecfg[N], target[N], setip/clrip, genmsi
- `setip(source_id)` → 查 target → 写目标 hart IMSIC `seteipnum`

### Phase 3: H-mode + 两阶段翻译 (~3 周)

Hypervisor CSR, VS-mode 上下文, HLV/HSV 指令,
`hgatp` 两阶段地址翻译, `HFENCE.VVMA/GVMA`

### 依赖

```
Phase 0 ──┬── Phase 1 ── Phase 2
          └── Phase 3
```

Phase 0 为硬性前置 — 所有后续工作依赖编译时配置框架。
